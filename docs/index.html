Chaturbate Recorder

Enregistreur de lives multi-stream pour Windows — sécurité, qualité et confidentialité configurables.

Télécharger la dernière version Code source (GitHub)

Fonctionnalités

Multi-stream

Enregistre plusieurs lives en parallèle sans ouvrir plusieurs instances de l'application.

Qualité & codec au choix

Meilleure qualité, moyenne ou minimale ; réencodage optionnel en H.264/H.265 sans jamais toucher au fichier original.

Format de sortie

MP4, MKV (plus robuste face à un arrêt brutal) ou MOV.

Sécurité intégrée

Vérification du hash et de la signature de yt-dlp/ffmpeg, sandbox de chemins, détection d'ACL permissives, blocage des emplacements d'exécution suspects.

Confidentialité

Support d'un proxy SOCKS5/HTTP et import de cookies navigateur pour le contenu réservé aux comptes connectés.

Mises à jour intégrées

Bouton "Rechercher une mise à jour" qui vérifie les releases GitHub et installe la nouvelle version automatiquement.

Installation

Télécharge le ZIP de la dernière release, extrais-le où tu veux, et lance ChaturbateRecorder.exe.

Nécessite le .NET 10 Desktop Runtime. yt-dlp.exe et ffmpeg.exe ne sont pas inclus (voir le README du dépôt) pour rester neutre vis-à-vis de leurs licences respectives — place tes propres binaires dans un dossier Tools\ à côté de l'exécutable.

Code source

Le projet est open source sur GitHub. Contributions, retours et rapports de bugs sont les bienvenus via les issues du dépôt.
