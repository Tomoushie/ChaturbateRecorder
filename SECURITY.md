# Politique de sécurité

🇫🇷 Français (cette section) · 🇬🇧 [English](#security-policy)

## Versions supportées

Projet maintenu par une seule personne, sans SLA formel : seule la
**dernière release publiée** reçoit des correctifs de sécurité. Merci de
toujours vérifier que tu utilises la dernière version avant de signaler
un problème (bouton "Rechercher une mise à jour" dans l'application, ou
[dernière release](https://github.com/Tomoushie/ChaturbateRecorder/releases/latest)).

## Signaler une vulnérabilité

**Ne pas ouvrir de ticket public** pour une vulnérabilité de sécurité —
utilise l'un des canaux privés suivants :

- [GitHub Security Advisories](https://github.com/Tomoushie/ChaturbateRecorder/security/advisories/new)
  ("Report a vulnerability" dans l'onglet **Security** du dépôt) — canal
  préféré, garde l'échange privé jusqu'à correction.
- À défaut, un message privé via le profil GitHub
  [@Tomoushie](https://github.com/Tomoushie).

Merci d'inclure : la version concernée, une description du problème, les
étapes pour reproduire, et l'impact potentiel si tu l'as évalué.

## À quoi t'attendre

Meilleur effort, sans délai garanti (projet personnel, pas d'équipe
dédiée) — mais les rapports de sécurité sont pris au sérieux et
traités en priorité par rapport au reste du backlog. Tu seras tenu·e
informé·e de l'avancement.

## Hors périmètre

- **Vulnérabilités dans yt-dlp ou ffmpeg** : ce sont des binaires tiers
  invoqués comme sous-processus, pas du code de ce dépôt — signale-les
  directement aux projets concernés
  ([yt-dlp](https://github.com/yt-dlp/yt-dlp/security),
  [ffmpeg](https://ffmpeg.org/security.html)).
- **Contenu enregistré via l'application** : ce dépôt ne couvre que la
  sécurité technique du logiciel lui-même, pas la légalité ou le contenu
  de ce que tu choisis d'enregistrer.

## Security Policy

🇬🇧 English (this section) · 🇫🇷 [Français](#politique-de-sécurité)

## Supported versions

Solo-maintained project, no formal SLA: only the **latest published
release** receives security fixes. Please make sure you're on the
latest version before reporting an issue ("Check for updates" button in
the app, or the
[latest release](https://github.com/Tomoushie/ChaturbateRecorder/releases/latest)).

## Reporting a vulnerability

**Do not open a public issue** for a security vulnerability — use one of
these private channels instead:

- [GitHub Security Advisories](https://github.com/Tomoushie/ChaturbateRecorder/security/advisories/new)
  ("Report a vulnerability" under the repo's **Security** tab) —
  preferred channel, keeps the exchange private until fixed.
- Otherwise, a private message via the
  [@Tomoushie](https://github.com/Tomoushie) GitHub profile.

Please include: the affected version, a description of the issue, steps
to reproduce, and the potential impact if you've assessed it.

## What to expect

Best effort, no guaranteed timeline (personal project, no dedicated
team) — but security reports are taken seriously and prioritized over
the rest of the backlog. You'll be kept informed of progress.

## Out of scope

- **Vulnerabilities in yt-dlp or ffmpeg**: these are third-party
  binaries invoked as subprocesses, not code from this repo — report
  them directly to the relevant projects
  ([yt-dlp](https://github.com/yt-dlp/yt-dlp/security),
  [ffmpeg](https://ffmpeg.org/security.html)).
- **Content recorded through the app**: this repo only covers the
  software's own technical security, not the legality or content of
  what you choose to record.
